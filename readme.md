# Task 3: Interactive Temperature Converter Website

## 📌 Project Summary
An interactive web utility that converts temperature inputs between **Celsius, Fahrenheit, and Kelvin**. Built with HTML5, CSS3, and Vanilla JavaScript, it features real-time input validation, error handling for absolute zero limits, and simultaneous multi-unit output displays.

---

## ✅ Feature Checklist Compliance
- [x] **Numeric Input Field:** Built with HTML `<input type="number">` and validated via JavaScript against empty or non-numeric inputs.
- [x] **Unit Selector:** Clean drop-down selection allowing user input unit selection (Celsius, Fahrenheit, Kelvin).
- [x] **Simultaneous Multi-Unit Output:** Shows output across all 3 units simultaneously in real-time.
- [x] **Click / Key Action:** Convert button and Enter-key listener to trigger computation.
- [x] **Absolute Zero Edge Case Handling:** Validates and flags absolute zero violations ($<-273.15^\circ\text{C}$, $<-459.67^\circ\text{F}$, $<0\text{ K}$) with user-friendly error prompts.
- [x] **Centred UI & Responsive Design:** Clean, centered card interface using CSS Flexbox/Grid that adjusts seamlessly on mobile and desktop.

---

## 🛠️ Tech Stack
* **HTML5**
* **CSS3** (Flexbox, CSS Grid)
* **JavaScript (Vanilla ES6)**

---

## 🚀 How to Run
Open `index.html` in any modern browser.
