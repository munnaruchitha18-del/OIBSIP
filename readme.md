# Task 2: Personal Portfolio Website

## 📌 Project Summary
A clean, responsive personal developer portfolio website created for **Ruchitha Muniraj**. Built using semantic HTML5, CSS3, Google Fonts typography, and CSS variables for consistent design tokens.

---

## ✅ Feature Checklist Compliance
- [x] **Hero Section:** Full profile header featuring name, role title, CTA buttons, and custom avatar placeholder.
- [x] **About Me:** Paragraph overview highlighting background, technical interests, and career goals.
- [x] **Skills Matrix:** Grid display covering core technical competencies (HTML, CSS, JS, Python/Java, Git).
- [x] **Projects Showcase:** 3 project cards with title, description, technology tags, and GitHub repository links.
- [x] **Contact Section:** Direct contact information with email and GitHub/LinkedIn channels.
- [x] **Smooth Scroll Navigation:** Native CSS smooth scrolling across section anchors.
- [x] **Responsive Layout:** Adapts seamlessly between mobile devices and desktop views.

---

## 🛠️ Tech Stack
* **HTML5**
* **CSS3** (Flexbox, CSS Grid, Custom Properties)
* **Google Fonts** (Inter font family)

---

## 🚀 How to Run
Open `index.html` directly in your browser.
