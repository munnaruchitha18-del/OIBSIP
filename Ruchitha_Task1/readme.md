# Task 1: Product Landing Page

## 📌 Project Summary
A clean, responsive static landing page built for **Aura**, a modern productivity software product. This project focuses on semantic HTML5 structure, modular CSS3 styling, and responsive layout management using Flexbox and Grid.

---

## ✅ Feature Checklist Compliance
- [x] **Sticky Navigation:** Persistent navbar with logo, menu links, and call-to-action.
- [x] **Hero Section:** Clear value proposition headline, subtitle, and action buttons.
- [x] **Multiple Content Sections:** Features grid, About section, and Testimonials.
- [x] **Footer:** Links and social channel placeholders.
- [x] **Consistent Palette:** Cohesive slate/blue design system built with CSS variables.
- [x] **Responsive Layout:** Flexbox & CSS Grid adapt seamlessly across desktop and mobile screens.
- [x] **Clean Typography:** Hierarchy using modern system fonts and standard sizing scale.

---

## 🛠️ Tech Stack
* **HTML5**
* **CSS3** (Flexbox, Grid, CSS Custom Properties)

---

## 🚀 How to Run
Open `index.html` directly in any web browser.
